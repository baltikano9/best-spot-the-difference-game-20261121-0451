**Twin Lanterns — Spot the Difference**: an original spot-the-difference game drawn entirely with Canvas 2D code. Three scenes (Lantern Festival, Star Observatory, Seaside Bakery at Dawn) each hide 7 clever differences between two side-by-side pictures — a flipped crescent moon, an unlit lantern, a cat's tail, a changed star count and more. Click a difference on either picture to ring it on both, race the 3-minute timer bar, spend hints wisely (150 points, 3 per scene), and chain scene bonuses into a final score. No assets, no network: every picture, sound and animation is generated by the game's own code.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `game/` and `screenshots/` to `out/` and writes `out/dossier.json`. To play, serve the game folder with `node serve.ts --port 8123` and open http://localhost:8123 in a desktop browser.
